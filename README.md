# Spentee

Spentee is a fun and intelligent personal finance app that helps you track expenses, manage your budget, understand spending habits, and save money smarter.

## Features

- **Personalized Onboarding & Mascot Experience**: Interactive guide and playful financial companion.
- **Visual Finance Dashboard**: Track daily balance, view recent spending breakdown, and manage transactions.
- **Smart Analytics & Insights**: Category-level breakdown and spending trends.
- **Gamified Challenges & Leaderboards**: Complete daily financial tasks and stay within budget.

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.24+ or higher)
- Android Studio / Android SDK with Google Pixel 10 Pro emulator or physical device

### Run the App

```bash
# Get dependencies
flutter pub get

# Run on connected device or emulator
flutter run
```
